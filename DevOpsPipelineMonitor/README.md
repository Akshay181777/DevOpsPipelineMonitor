# DevOps Pipeline Monitor

A WPF desktop application that simulates Jenkins and GitHub Actions CI/CD pipeline monitoring.

## Features

- Pipeline status dashboard
- Success / Failed / Running tracking
- Pipeline logs viewer
- Auto refresh every 30 seconds
- JSON parsing using Newtonsoft.Json
- Jenkins and GitHub Actions style monitoring

## Technologies

- C#
- WPF
- .NET 8
- Newtonsoft.Json
